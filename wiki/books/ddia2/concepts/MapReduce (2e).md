# MapReduce

The 2004 batch programming model — map, shuffle by key, reduce — that defined a decade of distributed data processing. The 2nd edition keeps it for the concepts and states plainly that it is largely obsolete in practice.

See [[MapReduce (2e)]] and [[Dataflow Engines (2e)]].
