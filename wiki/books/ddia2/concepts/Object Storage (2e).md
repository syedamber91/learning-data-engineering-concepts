# Object Storage

Durable, effectively unbounded blob storage addressed by key, with no filesystem semantics. In the 2nd edition it has largely displaced HDFS as the substrate for batch processing and increasingly backs log brokers and warehouses too.

See [[Distributed Filesystems (2e)]] and [[Separation of Storage and Compute (2e)]].
