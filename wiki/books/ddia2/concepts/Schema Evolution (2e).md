# Schema Evolution

Changing the shape of your data without breaking the code that reads or writes it. Backward compatibility means new code reads old data; forward compatibility means old code reads new data — and rolling upgrades need both.

See [[Formats for Encoding Data (2e)]] and [[Modes of Dataflow (2e)]].
