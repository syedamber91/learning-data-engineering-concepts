# Sharding

Splitting a dataset across nodes so each holds a subset. The 2nd edition renames the 1st edition's "partitioning" to sharding throughout, to free up "partition" for the network kind.

See [[Sharding of Key-Value Data (2e)]], [[Operations - Automatic Versus Manual Rebalancing (2e)]], and [[Request Routing (2e)]].
